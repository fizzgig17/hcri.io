TKLamp Live Logger in your browser

Records a TKLamp TK2303D tester over USB in Chrome or Edge, with exact start and end times, then uploads and shares the run on hCRI.io. Instructions, and the Python version

This browser can't open USB serial devices

Reading the tester needs Web Serial, which is in Chrome and Edge on a Mac, Windows or Linux computer (not Safari, Firefox or phones). You can still try everything with Try without a tester, and use the Python version.

Run limits (blank = off; remembered on this browser)
Start at: Start run waits until the light reaches this level. Stop below: ends the run when the output stays below it for 3 s (only after it has been above it). No readings: ends the run when the tester has been silent that long (default 5 minutes). A run that stops by itself is saved at once under its suggested name; rename or upload it from History.

Calibrate the scale

Put a lamp of known output in the sphere and leave it steady. Enter its lumens, then Measure. It averages 8 seconds of readings and works out the counts per lumen.
